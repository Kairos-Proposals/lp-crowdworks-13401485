案件理解

この募集、こう読み解きました。

単発の制作依頼ではなく「進行中プロジェクトの仕上げ」。既存のトンマナ・構成を壊さず、限られた期間で均質な品質に揃えることが最大のポイントだと考えています。

「TOPページはこれから作り込み、コラムは各サイト50本ずつ、既存ページはPC・スマホともに調整が必要。 求人サイトなのでフォーマットは似ているが、それでも400ページ規模を1ヶ月・10万円台でやり切る体制がいる」 ——募集内容を、私たちはこう捉えています。

KAIROS / 案件理解メモ
01
4サイト同時進行のため、テンプレート化と分業設計が仕上がりのカギ。
02
TOP・全体・コラムで求められるスキルが異なる（構成／コーディング／文章生成／画像加工）。
03
求人サイト特有の「同じ構造の量産」を、AIと定型フローでスピード対応。
04
1ヶ月という納期の中でPC/スマホ双方の表示崩れを防ぐチェック体制が必要。
提供できる価値

Kairosが、仕上げ工程を巻き取ります。

コーディング・AIライティング・画像加工を1チームで完結。工程間の伝言ゲームが発生しません。

VALUE 01

TOPページ制作一式

構成案からAIによるテキスト作成、画像加工、コーディングまでをワンストップで仕上げます。

VALUE 02

PC/SPコーディング調整

既存デザインを踏襲しつつ、4サイト共通のチェックリストで表示崩れ・レイアウト崩れを潰し込みます。

VALUE 03

コラム大量生成パイプライン

各サイト50本×4サイト＝200本規模のコラムを、AIライティング＋人の校正フローで効率的に生産。

VALUE 04

画像加工・流し込み

アイキャッチ・バナー類のトンマナを統一し、コラムページへの流し込みまで一気に対応。

VALUE 05

4サイト横断の進行管理

サイトごとの進捗・残タスクを可視化し、1ヶ月の中でも遅延しない体制で報告します。

進め方

1ヶ月・4週間での完走イメージ。

4サイトを並行運用しながら、優先度の高いページから確実に仕上げていきます。

W1
現状把握・素材共有

4サイトの現状データ・デザインルール・コラムのフォーマットを確認し、制作ルールを確定。

W2
TOP仕上げ／記事生成開始

TOPページのテキスト・画像・コーディングを完成させつつ、コラム記事の量産をスタート。

W3
全体コーディング調整

PC・スマホの表示調整と、コラムページへの画像・テキスト流し込みを並行して進行。

W4
最終チェック・納品

4サイト横断で表示崩れ・誤字・リンク切れを最終確認し、順次納品します。

まずは、4サイトの現状を見せてください。

現在の進捗・デザイン・コラムのフォーマットを拝見できれば、初回のお打ち合わせで具体的な分担とスケジュールをご提案します。
